# The Mortice Kern Systems Awk

This version of `awk` was originally written by Mortice Kern Systems,
who sold Unix tools for different non-Unix systems, such as MS-DOS
and Windows.

Solaris adopted it for their POSIX-compatible `awk`, and it made
its way out into the world via OpenSolaris.

This code was retrieved in September of 2026 from the official
[Illumos Git mirror](https://github.com/illumos/illumos-gate).
There, it lives in `/usr/src/cmd/awk_xpg4.`

The goal of this repo is to make the MKS `awk` function well
on a current-day GNU/Linux system, not to make it super portable
or to Autoconfiscate it.
